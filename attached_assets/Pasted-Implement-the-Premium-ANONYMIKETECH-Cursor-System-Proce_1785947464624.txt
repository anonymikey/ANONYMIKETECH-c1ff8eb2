Implement the Premium ANONYMIKETECH Cursor System

Proceed with implementing the Premium Cursor System as a global interaction layer.

This is not a new page or standalone feature. It must integrate seamlessly with the existing cinematic experience.

Do not modify the Hero frame engine, cinematic scroll engine, loader, routing, animations, branding, or existing layouts.

Architecture

Create the following reusable structure:

components/cursor/
│
├── PremiumCursor.tsx
├── CursorCore.tsx
├── CursorRing.tsx
├── CursorParticles.tsx
├── CursorMagnet.ts
├── CursorContext.tsx
├── useCursor.ts
└── cursor.css

Mount the cursor globally inside the application root so every page automatically inherits it.

Cursor Design

electric blue glow

Motion

Do not directly follow the pointer.

Use requestAnimationFrame interpolation.

Movement should feel physical and cinematic.

Target smooth 120Hz capable rendering.

GPU accelerated only.

Particle System

Generate a lightweight particle trail.

Maximum:

20 particles

Each particle should:

recycle instead of recreating
fade naturally
shrink over time
random blue/cyan
occasional gold accent

Never create unnecessary DOM elements.

outer ring expands

Use smooth easing.
